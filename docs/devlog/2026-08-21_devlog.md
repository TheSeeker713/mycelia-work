## 12:35 — Phase 0: ripped out the online updater

The Settings "Check for updates" button was pointed at a domain I
guessed (`updates.myceliainteractive.com`) and a Cloudflare bucket that
never existed. Clicking it would just sit there looking like the app
couldn't reach anything, which for an internal-only tool is a lie
dressed up as a feature.

Took the whole path out. `UpdateCheck.tsx`, `updater.ts`, the vitest
file, `tauri-plugin-updater`, `tauri-plugin-process` (it only existed
to relaunch after an install). Settings now has one sentence: rebuild
and reinstall, `npm run tauri build`. The GitHub workflow still builds
an NSIS installer on a `v*` tag as a private draft, but it doesn't
assemble `latest.json` or push anything to R2.

640 tests green after the removal. Typecheck clean. Cargo test next in
the same close-out.

CLAUDE.md still says phases auto-chain. This run is gated per the
master plan and AGENTS.md. Noting it so I don't forget the docs
disagree.

## 12:45 — Phase 1: Retry actually looks like Retry, and Grok is 4.6

Clicked Retry on a failed Library report yesterday (in the audit) and
nothing moved. The row stayed Failed because `retryJournal` never put
it back on pending before calling the model. Same class of bug on
project reports, which didn't even have a Retry button.

Now Retry sets pending first, the bar shows Generating, and a second
click is ignored while that job is in flight. Muse was skipping the
queue and firing on two-letter drafts; it now goes through
`useGhostText` with the 12-character floor and a faint "…" while it
thinks. Ghost text fields get the same thinking mark.

Settings said Grok 4.5. The constant was 4.5 and never even passed as
`--model` when Grok was on. It's 4.6 now, and it actually gets sent.
Clock-out "AI writes it" opens Library the same way "I'll write it"
already did, so you can watch Generating instead of staring at the
clocked-out dashboard.

647 tests. Typecheck clean. Cargo 18.
